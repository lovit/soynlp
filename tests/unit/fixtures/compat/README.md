# Master compatibility fixtures

`master.json` and `word-model.pkl` were generated by running the original
`master` commit `503eaee` in an isolated directory with Python 3.12.
The sentences and tokenizer expectations use Korean text; extraction uses
`WordExtractor(min_frequency=2, verbose_points=0)`,
`LRNounExtractor_v2(verbose=False).train_extract(min_noun_frequency=2)` and
`Bigram(min_frequency=1, verbose=False)`.
The pickle is a checked-in test fixture produced by master, not an input
format for new CLI resources.

The compatibility port preserves those algorithms. It corrects existing
runtime errors: the v1 extraction threshold argument, the News extractor's
base dictionary variable, string postprocessing arguments, LR fallback
score lookup, and empty corpus length. Progress output uses logging.
